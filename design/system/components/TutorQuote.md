# TutorQuote

The tutor's only voice: one short line at lesson start, after a pass or a fail, and on streak milestones.

- Box: full width (342px), 2px border, padding 24 14 14; label tab sits on the top border (top −13px, left 12px, padding 0 8px, `pixel` 20px, `ink-inverse`).
- Text: `pixel` 24/26 `ink`, max 2 sentences.
- Variants: **start** = `yellow`; **pass** = `cyan` + "✓"; **fail** = `pink` + "✗". The tab text names the persona or the result.
- Persona is a Settings choice; the persona only changes wording, never layout. Optional 48px square avatar left of the tab on desktop.
